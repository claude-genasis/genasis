# Ralph Progress Log — GenasisTrialApp (ralph/trial-webapp)

## Codebase Patterns
- Next.js project root is `/work/genasis/trial-app/` (not `apps/trial-app/` as PRD wording suggests; ralph workspace lives in `ralph/` sibling dir).
- App Router structure: `app/layout.tsx` is the root layout, `app/page.tsx` the landing page, `app/globals.css` holds Tailwind directives.
- TypeScript strict mode is enabled; run `npm run typecheck` (alias for `tsc --noEmit`) for type validation.
- Tailwind v3 (`tailwind.config.ts` + `postcss.config.js`); content scan is restricted to `app/**` and `lib/**`.
- `tsconfig.json` excludes `node_modules` and `ralph/` so the ralph workspace doesn't pollute typechecking.
- Path alias `@/*` resolves from project root.
- HTML root lang is `ko` (Korean is the primary user-facing language).
- Use `next` 15.5.x (15.1.x has CVE-2025-66478); confirm via `npm view next versions`.
