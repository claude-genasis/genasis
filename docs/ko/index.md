[GitHub 에서 전체 README 보기 →](https://github.com/claude-genasis/genasis/blob/main/README.ko.md)

## 설치

```bash
curl -fsSL https://raw.githubusercontent.com/claude-genasis/genasis/main/install.sh | sh
```

설치기는 한국어/영어 중 하나를 선택하라고 묻습니다. `--lang both` 는 의도적으로 거부합니다; [`docs/ko/impact-of-multilang-prompts.md`](https://github.com/claude-genasis/genasis/blob/main/docs/ko/impact-of-multilang-prompts.md) 참조.
