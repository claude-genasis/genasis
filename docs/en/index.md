# Genasis

> 🇺🇸 **English** | [🇰🇷 한국어](../ko/)

Bolt-on agentic team layer for Claude Code. Plane × Mattermost × TDD × Design hot-swap × Schema-as-code × Monitor — non-destructively attached to **any** existing agent team.

[Read the full README on GitHub →](https://github.com/claude-genasis/genasis#readme)

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/claude-genasis/genasis/main/install.sh | sh
```

The installer prompts you to choose English or Korean for the agent overlay. `--lang both` is rejected by design; see [`docs/impact-of-multilang-prompts.md`](https://github.com/claude-genasis/genasis/blob/main/docs/impact-of-multilang-prompts.md).
